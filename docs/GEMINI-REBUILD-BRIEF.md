# Bakunawa Rebuild Brief (Gemini, macOS, 1 hour)

Rebuild the Bakunawa MVP with Gemini CLI from the Spec Kit documents, copying the proven
infrastructure files as they are so time goes into features, not debugging. The reference build
is `github.com/japanesekenji/mapbk` (branch `main`). Check the hackathon rules first: if
prepared code is not allowed, use only the documents in tier C and write everything else live.

**1-hour scope:** P1 stories only: map (US1), SOS (US3), report (US2), then deploy.
Verification, facilities and the incident list (US4 to US6) are stretch goals.
**30-minute option:** if prepared code is allowed, use section 7 instead (copy almost everything,
Gemini writes 6 pages).

## 1. Mac setup (before the event, 10 minutes)

```bash
xcode-select --install                 # git
brew install node@22 gh                # Node 22 LTS, GitHub CLI
npm install -g @google/gemini-cli      # Gemini CLI
uvx --from git+https://github.com/github/spec-kit.git specify init bakunawa --ai gemini
```

No Docker. Use the hosted Supabase project (already migrated and seeded) or a new one.

## 4. `GEMINI.md` (create first; Gemini CLI loads it every session)

```markdown
# Bakunawa: rules for this project
- Follow specs/001-disaster-response-platform/{spec,plan,data-model,contracts/*}.md and
  .specify/memory/constitution.md. Do not change files listed as "copied as-is" in
  docs/GEMINI-REBUILD-BRIEF.md section 2 unless told to.
- Stack: Next.js 16 App Router, React 19, TypeScript strict, Tailwind 4, MapLibre GL 6,
  Supabase (supabase-js, @supabase/ssr), zod 4. No Docker. Node 22.
- Next 16: middleware is src/proxy.ts; params, searchParams, cookies() are async;
  wrap components using useSearchParams() in <Suspense>. Cache Components is off.
- Access control lives in Postgres RLS and RPC functions. Never expose the service-role key
  to client code; only route handlers import src/lib/supabase/service.ts.
- UI must match the design handoff (colors in src/styles/tokens.css, icons from
  src/components/icons/Icon.tsx). Mobile first, 360px minimum width.
- After each step run: npm run typecheck && npm run lint.
```

## 6. Pitfalls and fixes (all hit in the reference build)

| Symptom | Fix |
|---|---|
| Middleware never runs | Next 16 renamed it: `src/proxy.ts` exporting `proxy()` |
| `params`/`cookies()` type errors; `LayoutProps` not found | Await them; run `next typegen` before `tsc` |
| "cookies() outside Suspense" or prerender errors | Cache Components off; wrap `useSearchParams()` users in `<Suspense>` |
| `maplibre-gl has no default export` | `import { Map, Marker, setWorkerUrl } from "maplibre-gl"` |
| Blank map, "Worker failed to load" | Copy worker files to `public/maplibre/` (postinstall) and call `setWorkerUrl("/maplibre/maplibre-gl-worker.mjs")` |
| Map canvas only 52px tall | `maplibre-gl.css` forces `position:relative`; give the container an inline `style={{position:"absolute",inset:0}}` |
| No pins, or pins only after tiles load | Add sources in `style.load`; never gate `setData` on `isStyleLoaded()` |
| Visitors see rejected incidents | SQL: `coalesce(app_role() in (...), false)`; `NOT NULL` is NULL and skips checks |
| Views writable by anon | Supabase default grants; `revoke all ... grant select` (migration 0701) |
| PostGIS type not found in functions | Types live in `extensions`; use `extensions.geography` and `set search_path = public, extensions` |
| Pins in the wrong place | WKT is `POINT(lng lat)`: longitude first |
| Photo compression hangs offline | `browser-image-compression` worker loads from a CDN: `useWebWorker: false` |
| React lint: impure render / setState in effect / ref in render | `useState(() => Date.now())`, derive instead of setting, `useEffectEvent` |
| zod errors on `required_error` | zod 4: `z.enum(values, { error })`, `z.literal(true, { error })` |
| Seeded users cannot sign in | Insert `auth.identities` too and empty strings for token columns (see seed.sql) |
| `supabase db push` does nothing | Non-interactive needs `--yes`; use `--remote=<url>`; hosted DB via Session pooler (IPv4, port 5432) |
| `psql -c` ignores `:vars` | Pipe SQL through stdin with `-v name=value` |
| Vercel `404 NOT_FOUND` on every page | `vercel.json` with `"framework": "nextjs"` |
| Map data empty a day later | Seed times are relative; re-run seed.sql before the demo |
| Public demo password | README password is public; reset demo account passwords on hosted projects |

## 7. 30-minute variant (copy almost everything; Gemini writes 6 pages)

Use this when the rules allow prepared code. About 90% of the code is copied; Gemini assembles
the remaining pages from copied components and deploys. Dry run on 2026-11-21: the copied set
alone installs, type-checks, lints with 0 errors and builds (routes `/profile`, `/report`,
`/respond`, `/sos` and all 6 API routes).

**Copy** (from an empty project folder; `REF` is a clone of `mapbk`):

```bash
git clone git@github.com:japanesekenji/mapbk.git ~/mapbk          # once, before the event
mkdir ~/bakunawa && cd ~/bakunawa
REF=~/mapbk sh ~/mapbk/scripts/copy-30min.sh
npm ci                                                             # about 1 to 2 minutes
cp ~/mapbk/.env.example .env.local                                 # then paste the 3 Supabase values
```

The script copies: `package.json`, `package-lock.json`, `tsconfig.json`, `eslint.config.mjs`,
`.gitignore`, `next.config.ts`, `vercel.json`, `.env.example`, `public/brand/`,
`scripts/copy-maplibre-worker.mjs`, `supabase/` (config, seed, 17 migrations), `src/proxy.ts`,
`src/styles/`, `src/lib/` (all, including generated types), `src/components/` (all),
`src/app/api/` (6 routes), `src/app/layout.tsx`, `src/app/globals.css`,
`src/app/(public)/layout.tsx`, the 4 heavy pages `report`, `sos`, `respond`, `profile`, plus
`specs/`, the constitution and `docs/`. Then create `GEMINI.md` from section 4 and add the line:
"All files except the 6 pages listed in section 7 are copied; do not modify them."
